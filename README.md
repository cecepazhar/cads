# CADS — CAFramework Design System

Unified Svelte 5 component library, machine-readable design tokens, and application templates for the entire CA product ecosystem (CATerm, CAMark, CAStudio, CACash, FathStore, etc.).

## 📦 Features
- **Zero-knowledge & Local-first Ethos**: Ultra-lightweight, high-performance Svelte 5 Runes.
- **Monochrome Foundation**: Slate & pitch-black default surface (`#0A0A0C`) with strict hierarchy.
- **Pro Theming**: Dynamic single CSS variable override (`--ca-brand`) for custom accent palettes.
- **Components Included**: Button, Badge, Card, Table (DataGrid), Modal/Dialog, Alert/Toast, Sidebar, Icon, Language Switcher, Theme Switcher.
- **Full Screen Templates**: Splash Screen with inspiring tech quotes, CAFramework Single Sign-On Login, Telemetry Dashboard, and AI Co-Pilot Chat.

## 🚀 Quick Start
```bash
npm install
npm run dev   # Start interactive showcase on http://localhost:5173
npm run build # Build production library & showcase
```
