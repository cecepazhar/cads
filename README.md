## 🌟 Overview
**`@cecepazhar/caui`** adalah design system resmi, pustaka komponen Svelte 5 modern, dan token desain monoline wireframe tech-brutalist yang menjadi fondasi seluruh 17 aplikasi di ekosistem **CA Family** (*CATerm, CAMark, CAStudio, CACash, CATama, FathStore, dll*).

## 🚀 Instalasi & Cara Pakai

Di proyek Anda, pasang paket `@cecepazhar/caui`:

```bash
pnpm add @cecepazhar/caui
# atau via local workspace link
pnpm add file:../../caui
```
